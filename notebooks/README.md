# Notebook Guide

These notebooks are teaching companions for the HUXt Gaussian Process surrogate workflow.
Prepared CME seed parameters are listed in `data_dir/events.csv`; the notebooks and scripts assume event inputs have been generated under `data_dir/sw/<event>/`.
For script-level options, see the project `README.md`; for the input-preparation workflow, see `Tutorial.md`, which explains `scripts/generate_huxt_input.py`.

Set up the environment (see the Installation section in the project `README.md` -
conda recommended) and register a kernel named `conecast`:

```bash
conda activate conecast          # or: source .venv/bin/activate
python -m ipykernel install --user --name conecast --display-name "Python (conecast)"
```

Open the notebooks in this order:

1. `01_gp_tutorial.ipynb` - general Gaussian Process theory and standard worked examples (intuition, the regression formula, a 1-D fit, and a 2-input surrogate).
2. `02_huxt_runs.ipynb` - walks every `generate_huxt_input.py` operation (events.csv -> GONG -> WSA+ -> sub-Earth track -> boundary -> seed config) as an independent, reimplemented task, running the WSA+ map live (GONG download guarded).
3. `03_arrival_detector_examples.ipynb` - runs HUXt for two Cone-CMEs (one aimed at Earth, one rotated away) to show the arrival detector turning a speed series into a hit/miss + arrival time, reproducing what `gp_huxt_surrogate.py visualize-threshold` draws.
4. `04_gp_huxt_application.ipynb` - walks every `gp_huxt_surrogate.py` operation (design -> run/detect -> fit -> the five analyze steps) as an independent, reimplemented task, including one live HUXt seed run.

The notebooks are generated by:

```bash
python scripts/create_gp_notebooks.py
```
